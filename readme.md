# Rio Archive Viewer Plugins

## Overview
If a namespace has Archive Viewer enabled, every time an object is archived or found by indexing, 
Rio will search for a plugin that matches teh file extension

> Example: myMovie.mp4 will fire the plugin mp4.lua (case-insensitive)

## Plug-in Workflow
Typically, three options are scripted in an AV Pluigin:

1. Generate/register a Proxy (low-resolution video for identification and partial restore if enabled).
2. Genrate/register a Thumbnail (Small image for identification in tabular data or poster in video player).
3. Metadata generation and association (attach metadata generated by media utilities or AI).

## Available Libraries
Scripts can use packages in lib.

Note that they need to be imported using loadfile() and not require()
```lua
local lib_path = plugin_dir .. "/lib/" -- plugin_dir is global
local rio_utils = assert(loadfile(lib_path .. "rio_utils.lua"))()
```
[Available methods / API](docs/lib-api.md)
